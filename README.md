## Περιγραφή : Δικτυακή εφαρμογήπαραγγελίας και παραδοσης φαγητού από μικρά καταστήματα και food trucks , υλοποιημενη σε java /  Spring Boot με απομακρυσμένη βάση δεδομένων και ανεξάρτητη εξωτερική υπηρεσία παράδοσης.

## Ρόλοι εργασίας :
## Μέλος 1 :  Spring Boot Setup , Repositories και δημιουργία οντοτήτων use cases , Remote Data Base , Tests.
## Mέλος 2 : Security , Rest API Controllers + έλεγχοι εγκυρότητας εισόδου με σωστούς κωδικούς και μηνύματα σγάλματος  , Documentation.
## Mέλος 3 : Εξωτερική Black box υπηρεσία ( σε ξεχωριστη εφαρμογή που τρέχει σε δική της διεργασία και συνδέεται με την κύρια μέσω interface) , HTTP Client με Tests.
## Μέλος 4 : UI (WEB UI) , Τεχνικές αναφορές  , δημιουργία README για την σωστή χρήση της εφαρμογής.
